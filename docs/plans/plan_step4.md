## Why a campaign

Seven submissions with rolling-CV scores from 0.89 to 0.94 all landed at 0.939–0.945 on the
public board (noise std 0.006). From step 43 onward every model scores nearly everything as
licit, and equalising step means (sub_08) changed nothing. Historical CV therefore cannot see
the half of the test set that decides the ranking. Structural changes have to be tested where
they matter, one at a time, with a reference held fixed.

## Rules

- **Reference**: sub_07's pipeline (v2b features, tuned LightGBM, 5-seed bag), regenerated by
  `probes.py ref` and checked identical to the uploaded file.
- **One change per probe.** Each probe file differs from the reference by exactly one component.
- **Adoption**: paired public delta > +0.008, or two independent probes of the same change both
  > +0.004; and the far-window CV mean must not drop by more than 0.005 (veto).
- **Daily budget**: two probes + one confirmation (a re-test of a promising change with a
  different seed bag or a small variation).
- **Ledger**: `results.md` gains a "Probe campaign" table: date, file, change, reference, CV
  3-fold, CV horizon, far-window mean / min, public LB, delta vs reference, verdict.
- **Veto data**: far-window CV = the eight windows in `artifacts/cv_far_windows.csv`.

## Probe definitions (all in `probes.py`)

| name | change relative to the reference |
|---|---|
| `ref` | none |
| `identifiers_back` | + the six raw period-identifier columns |
| `topology` | + per-period graph topology: in/out degree, unlabelled-neighbour counts, DAG depth/height, PageRank (component size excluded) |
| `local_only` | only the local block (feat_1–93) with its drifting columns ranked |
| `rank7` | rank only the 7 drifting columns with >2,000 distinct values; feat_115 and feat_151 left raw |
| `anomaly_10` / `anomaly_20` | rank blend with an Isolation Forest fitted on licit training rows |
| `adv_weights` | training rows weighted by p(test | x) / p(train | x) from an adversarial classifier, clipped to [0.2, 5] |
| `self_train` | one round of pseudo-labels from confident test predictions (p > 0.9 → 1, p < 0.02 → 0), refit |
| `gnn_embed` | + embeddings from an inductive GraphSAGE (step 3) |
| `bag10` | 10-seed bag instead of 5 |

Each probe also reports the four standard folds and the eight far windows (three seeds) so the
CV veto is applied before upload.

## Exit conditions

- A change clears the adoption rule → it joins the reference, and the schedule restarts from the
  new reference.
- Nothing clears it after the first week → convert to the robustness track: `bag10`, feature
  clean-up, GNN for the report, student-number notebook, final selection of two submissions.
